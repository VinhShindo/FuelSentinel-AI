# FuelSentinel-AI
Hệ thống kết hợp dữ liệu từ cảm biến mức nhiên liệu đã hiệu chuẩn với thông số tốc độ xe và GPS. Bằng cách sử dụng các kỹ thuật xử lý tín hiệu, hồi quy tuyến tính và học máy (machine learning) tinh gọn, FuelSentinel-AI có khả năng phân tích và lọc nhiễu chính xác, giúp nhận diện các bất thường trong quá trình sử dụng nhiên liệu.
